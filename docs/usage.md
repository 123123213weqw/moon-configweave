# Request and result guide

Every example below is an executable fixture from `tests/cases.json`. The same cases run as MoonBit white-box tests on every backend (`fixtures_wbtest.mbt`) and through the Node CLI (`scripts/check.mjs`). Assertions cover the listed result fields; additional output fields are documented by the API and other fixtures. Error cases intentionally reject the request. This file is generated by `scripts/fixtures.py`.

## layer merge

Later layers override earlier ones key by key; origins record the override chain for every path.

```json
{
  "layers": [
    {
      "name": "base",
      "value": {
        "db": {
          "host": "local",
          "port": 1
        }
      }
    },
    {
      "name": "prod",
      "value": {
        "db": {
          "port": 2
        }
      }
    }
  ]
}
```

Expected result fields:

```json
{
  "config/db/host": "local",
  "config/db/port": 2,
  "origins//db/port": [
    "base",
    "prod"
  ]
}
```

## interpolation keeps type

A whole-string reference keeps the referenced type; an embedded reference is rendered into the text.

```json
{
  "layers": [
    {
      "name": "x",
      "value": {
        "n": 3,
        "copy": "${config:/n}",
        "message": "n=${config:/n}"
      }
    }
  ]
}
```

Expected result fields:

```json
{
  "config/copy": 3,
  "config/message": "n=3"
}
```

## secret aliases

Secrecy propagates from a secret environment variable through scalar and container aliases; masked lists every redacted path in code-unit order.

```json
{
  "layers": [
    {
      "name": "x",
      "value": {
        "db": {
          "password": "${env:KEY}"
        },
        "alias": "${config:/db}"
      }
    }
  ],
  "env": {
    "KEY": "secret"
  },
  "secret_env": [
    "KEY"
  ]
}
```

Expected result fields:

```json
{
  "config/db/password": "***",
  "config/alias": "***",
  "masked": [
    "/alias",
    "/db/password"
  ]
}
```

## env reference default

A :-literal fallback is used only when the target is absent; an empty string value is present and wins over the fallback.

```json
{
  "layers": [
    {
      "name": "x",
      "value": {
        "missing": "${env:NOPE:-fallback}",
        "present": "${env:SET:-unused}"
      }
    }
  ],
  "env": {
    "SET": "value"
  }
}
```

Expected result fields:

```json
{
  "config/missing": "fallback",
  "config/present": "value"
}
```

## pattern constraints

pattern is an unanchored search in the toolchain's regex dialect (explicit classes such as [0-9]; no \\d shorthands); anchor with ^ and $ to match the whole value. min_length and max_length count UTF-16 code units of strings or elements of arrays.

```json
{
  "layers": [
    {
      "name": "a",
      "value": {
        "version": "v12",
        "stage": "prod",
        "name": "abc",
        "tags": [
          "a",
          "b"
        ]
      }
    }
  ],
  "constraints": [
    {
      "path": "/version",
      "pattern": "^v[0-9]+$"
    },
    {
      "path": "/stage",
      "pattern": "^(dev|prod)$"
    },
    {
      "path": "/name",
      "min_length": 2,
      "max_length": 8
    },
    {
      "path": "/tags",
      "min_length": 1,
      "max_length": 3
    }
  ]
}
```

Expected result fields:

```json
{
  "valid": true,
  "issues": []
}
```

## export canonical text

export renders the resolved configuration as canonical JSON: object keys sorted, no whitespace, arrays in order.


Keys are ordered by UTF-16 code units (RFC 8785 order): shorter keys do not sort first.

```json

        "9": 4
```

```json
{
  "text": "{\"10\":3,\"9\":4,\"cache\":2,\"db\":1}"
```

## diff cannot see hidden secret changes

Diff compares redacted values by design; two different hidden secrets compare equal.

```json
{
  "operation": "diff",
  "old": {
    "layers": [
      {
        "name": "x",
        "value": {
          "k": "${env:S}"
        }
      }
    ],
    "env": {
      "S": "one"
    },
    "secret_env": [
      "S"
    ]
  },
  "new": {
    "layers": [
      {
        "name": "x",
        "value": {
          "k": "${env:S}"
        }
      }
    ],
    "env": {
      "S": "two"
    },
    "secret_env": [
      "S"
    ]
  }
}
```

Expected result fields:

```json
{
  "equal": true,
  "redacted": true
}
```

## diff reports masked override by origin

When a hidden value is overridden, the diff reports the changed origin chain without revealing either value.

```json
{
  "operation": "diff",
  "old": {
    "layers": [
      {
        "name": "defaults",
        "value": {
          "key": "${env:K}"
        }
      }
    ],
    "env": {
      "K": "k1"
    },
    "sensitive": [
      "/key"
    ]
  },
  "new": {
    "layers": [
      {
        "name": "defaults",
        "value": {
          "key": "${env:K}"
        }
      },
      {
        "name": "tenant",
        "value": {
          "key": "hardcoded"
        }
      }
    ],
    "env": {
      "K": "k1"
    },
    "sensitive": [
      "/key"
    ]
  }
}
```

Expected result fields:

```json
{
  "equal": false,
  "changes/0/path": "/key",
  "changes/0/type": "masked_override",
  "changes/0/before_origins": [
    "defaults"
  ],
  "changes/0/after_origins": [
    "defaults",
    "tenant"
  ]
}
```

## Host adapter

```sh
python -B scripts/files.py MANIFEST.json
```

A manifest is a request whose layers may name `file` entries (`.json` or `.toml`, resolved inside the manifest directory) and may list `allow_environment` names copied from the process environment. Read the current boundaries before using this adapter.
