# Moon ConfigWeave architecture

Status: development plan; functionality must be checked against release documentation.

目标：解释应用最终配置如何形成，并识别环境差异和错误覆盖。

核心模块：JSON/TOML 适配；路径和值模型；明确的合并策略；变量插值与环检测；来源追踪；类型约束；环境差异与遮罩；稳定导出和 CLI。每个最终值可以追溯到文件、层级及覆盖链。

三个场景：开发/测试/生产服务配置生成；CI 多平台矩阵配置合成；多租户应用默认值与租户覆盖。固定输入和预期结果，展示冲突为何发生、值来自何处、差异如何审查。

验收：一百环境/租户配置的合并结果与独立参考一致；重排无关键不影响结果；敏感值在普通日志及报告中均遮罩。失败验证覆盖插值循环、环境变量缺失、类型冲突、数组合并策略与深路径。十月不做远端配置中心，约束不扩展成 PolicyForge 的通用表达式系统。
